# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Resumen

Nos comprometemos a que participar en el proyecto sea una experiencia libre de acoso para todo el
mundo, sin importar edad, discapacidad, etnia, identidad o expresión de género, nivel de
experiencia, nacionalidad, apariencia, religión u orientación sexual.

**Se espera:** trato respetuoso, crítica centrada en el código y no en las personas, aceptar las
correcciones con buena fe y priorizar lo mejor para la comunidad.

**No se tolera:** insultos, acoso público o privado, lenguaje o imágenes sexualizadas, publicar
información privada de otras personas sin su permiso ni cualquier conducta inapropiada en un
entorno profesional.

## Regla específica de este proyecto

OSINEITOR es una herramienta de investigación. **Usarla, o usar los espacios del proyecto, para
investigar, exponer o acosar a otros participantes o a terceros** es una violación de este código
y supone la expulsión inmediata.

## Aplicación

Informa de cualquier incidente de forma privada a los mantenedores mediante el aviso privado de
GitHub (pestaña *Security* → *Report a vulnerability*, indicando que es un asunto de conducta) o
contactando con el propietario del repositorio. Todas las quejas se revisarán con
confidencialidad. Las consecuencias siguen las pautas del Contributor Covenant: corrección,
advertencia, expulsión temporal o permanente.
