# OSINEITOR

CLI OSINT en Python: investiga dominios, IPs, emails, usernames y otros identificadores con módulos
independientes y pivota entre las entidades que descubre. Todo el resultado se guarda en una base de
datos local y se exporta a JSON, Markdown, HTML, CSV, formatos de grafo, STIX y MISP.

> Úsalo solo sobre objetivos propios o con autorización expresa:
> [uso responsable](USO_RESPONSABLE.md).
